02 / SECURITY

Prime Security.

An evolving monitoring experiment: learning to transform SSH log messages into useful structured events.

Project status: Learning project. This page documents development, not a finished commercial product.

01 / THE PROCESS

The question

Can I turn noisy SSH messages into events I can review and understand?

02 / THE PROCESS

How I built it

Started with a Python collector for SSH events, added structured JSONL records and SQLite storage, then experimented with live monitoring and duplicate suppression.

03 / THE PROCESS

A challenge

Repeated connection events can make logs confusing. I learned to group related signals and avoid treating every message as an independent incident.

04 / THE PROCESS

What students can try

Write a Python script that reads a made-up sample log, extracts event categories and counts occurrences. Do not publish real IP addresses or authentication logs.

05 / THE PROCESS

What comes next

Improve event explanations and add a clear dashboard once the collector is reliable.

For students: Start with a small, authorized local exercise. Share your results without sharing private system information.
