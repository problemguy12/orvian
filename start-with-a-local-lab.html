ORVIAN / FIELD NOTES

Start with a local lab

The simplest way to learn networking is to observe systems you control.

Start close to home

A browser and a local HTTP server are enough to demonstrate requests, responses and ports.

Learn from observations

Change one thing at a time and observe what the browser and server report. Record your results rather than guessing.

Build responsibly

Use your own devices or an environment where you have explicit authorization. Keep your beginner services local.

This article reflects a personal learning project. It is not a claim that every planned feature is finished.
