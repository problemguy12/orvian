ORVIAN / STUDENT LEARNING CENTRE

Start small.
Build something real.

You don't need expensive equipment or prior experience. Follow one learning path, practice, and document what you discover.

01 / BEGINNER

Linux essentials

Learn to navigate your terminal, create folders and inspect files.

  1. Open your terminal and check your current directory with pwd.
  2. Create a practice folder with mkdir orvian-practice.
  3. Move into it with cd orvian-practice.
  4. Create a file with echo "Hello, ORVIAN" > hello.txt.
  5. Read the file with cat hello.txt.

Challenge: Create a second file and explain the difference between ls and cat.

02 / BEGINNER

Your first Python program

Turn a simple idea into code.

  1. Install Python from its official distribution for your device.
  2. Create a file named hello.py.
  3. Enter name = input("Your name: ") and print("Hello, " + name) on separate lines.
  4. Run python hello.py (or python3 hello.py).

Challenge: Ask the user which technology they want to learn.

03 / BEGINNER

Understand your network

Learn the difference between a device, an IP address, a router and a local service.

  1. Draw your own device-to-router network diagram.
  2. Find your device's local IP address using its network settings.
  3. Explain why a local address is different from a public address.
  4. Review the first local HTTP server exercise.

Challenge: Describe what happens when your browser opens a local web page.

Learning safely: Use your own devices or systems you have explicit permission to test. Never publish credentials, personal addresses or unredacted security logs.
