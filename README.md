# ORVIAN v2.0 — personal website

This is a static website and is independent of Prime Server.

## Preview
Open `index.html` in Acode preview or serve the folder locally with `python -m http.server 8080 --bind 127.0.0.1`. All pages use relative links.

## Pages
- `index.html`: homepage
- `projects.html`: four-project directory
- `prime-server.html`, `prime-security.html`, `network-lab.html`, `ai-experiments.html`: dedicated project stories
- `start-here.html`: Linux, Python, and networking starter exercises
- `journal.html` and `journal/`: journal index and three articles
- `about.html`: about and social links

## Privacy and publication
The Prime Server image is an AI-generated concept, not a real screenshot. Do not publish real dashboard screenshots without removing session information, internal network details, filenames and private logs. No website backend or connection to Prime Server is included.

## Deploy
Test every page locally. Then choose a static hosting provider that supports your `orvian.isroot.in` subdomain; only add DNS records after the host provides the exact target.
