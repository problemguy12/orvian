# ORVIAN — personal website v1

Independent static website for orvian.isroot.in. No connection to Prime Server.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design
- `script.js` — mobile menu, project stories, and starter lessons

## Preview
Open `index.html` in Acode or a desktop browser. For a local web-server preview, run `python -m http.server 8080 --bind 127.0.0.1` in this folder, then visit `http://127.0.0.1:8080` on the same device.

## Before publishing
- Review every project description and correct any details.
- Replace placeholder contact text only with public contact channels you're comfortable sharing.
- Do not upload credentials, private keys, API tokens, real security logs, or private IP/network information.
- Choose a static hosting provider that supports custom domains and confirm it supports `orvian.isroot.in` before changing DNS.
- Enable HTTPS and verify the deployed site on mobile and desktop.
