ORVIAN / PRACTICAL LESSON

Linux terminal essentials

Navigate folders, create files, and read terminal output.

01 / STEP

Know where you are

Use pwd to print your current directory. Use ls to list its contents.

pwd
ls
02 / STEP

Build a practice space

Create a folder in your home directory, then enter it. These commands affect only your practice area.

mkdir -p ~/orvian-practice
cd ~/orvian-practice
03 / STEP

Create and inspect files

Write a short message, read it, and count its lines.

printf "Hello, ORVIAN\n" > hello.txt
cat hello.txt
wc -l hello.txt
04 / STEP

Try it independently

Create a second file named notes.txt and list both files. Explain what each command did.
