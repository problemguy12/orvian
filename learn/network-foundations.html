ORVIAN / PRACTICAL LESSON

Networking: understand your LAN

Understand local addresses, routers, DNS, and the journey of a web request.

01 / STEP

Map your network

Draw your own phone, laptop, and router. Mark the connections between them.

02 / STEP

Understand addresses

A local IP identifies a device on a local network; a public IP identifies an internet-facing connection. Your router often translates between them.

03 / STEP

Test name resolution

If nslookup is installed, query a public documentation domain. This checks DNS, not whether a web service is healthy.

nslookup example.com
04 / STEP

Try it independently

Explain the difference between a DNS lookup and opening a web page. Use only networks and devices you own or are authorized to inspect.
