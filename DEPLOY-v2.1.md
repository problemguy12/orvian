# ORVIAN v2.1 deployment
1. Review the three new pages in `learn/` and the changes to `start-here.html`.
2. Upload the **contents** of the `orvian` folder to the root of your GitHub Pages repository (not the enclosing folder).
3. Check the GitHub Pages deployment before replacing the live version. Keep a backup of v2.0.
4. Visit https://orvian.isroot.in/sitemap.xml and the three lessons after deployment.
5. Add `https://orvian.isroot.in/sitemap.xml` in Google Search Console after verifying domain ownership.

This release adds SEO metadata, robots.txt, a complete sitemap, and three beginner lessons. No third-party visitor analytics script has been installed; Search Console is an optional external setup.
