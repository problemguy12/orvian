04 / AI & AUTOMATION

AI Experiments.

Experiments in Python commands, voice input and designing explicit permissions for software tools.

Project status: Learning project. This page documents development, not a finished commercial product.

01 / THE PROCESS

The question

Can I build a local assistant that helps with ordinary computer tasks?

02 / THE PROCESS

How I explored it

Created command-based Python assistant functions for system status and launching applications, then experimented with speech input and output.

03 / THE PROCESS

A challenge

Microphone access and speech libraries were not consistently reliable. I learned to keep text commands working independently of voice.

04 / THE PROCESS

What students can try

Write a text-only assistant with three commands: hello, help and exit. Keep actions explicit and avoid giving programs unnecessary permissions.

05 / THE PROCESS

What comes next

Document permission-aware integrations and test each capability before adding more.

For students: Start with a small, authorized local exercise. Share your results without sharing private system information.
